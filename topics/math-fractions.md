# Math - Fractions

## Level
Elementary (Grades 3-5)

## Description
Understanding and working with fractions. Covers basic concepts, equivalent fractions, comparing fractions, and simple operations.

## Key Concepts

### What is a Fraction?
A fraction represents a part of a whole. It has two parts:
- **Numerator** (top number): How many parts we have
- **Denominator** (bottom number): How many equal parts the whole is divided into

Example: 3/4 means 3 parts out of 4 equal parts

### Types of Fractions
- **Proper fraction**: Numerator < Denominator (e.g., 2/3)
- **Improper fraction**: Numerator >= Denominator (e.g., 5/3)
- **Mixed number**: Whole number + fraction (e.g., 1 2/3)

### Equivalent Fractions
Fractions that represent the same value:
- 1/2 = 2/4 = 3/6 = 4/8
- 1/3 = 2/6 = 3/9
- 2/3 = 4/6 = 6/9

### Comparing Fractions
- Same denominator: Compare numerators (3/5 > 2/5)
- Same numerator: Smaller denominator = larger fraction (1/3 > 1/4)
- Different: Find common denominator or convert to decimals

### Basic Operations
- **Adding** (same denominator): Add numerators, keep denominator
- **Subtracting** (same denominator): Subtract numerators, keep denominator
- **Simplifying**: Divide both by their GCD

## Exercise Types
- Identify parts of a fraction
- Find equivalent fractions
- Compare two fractions (greater/less/equal)
- Add fractions with same denominator
- Subtract fractions with same denominator
- Simplify fractions
- Convert between improper fractions and mixed numbers
- Word problems involving fractions
